## 1.  问题修复
### 1.1 解决登录问题：修改~/.claude.json配置文件，新增一行配置即可：
```bash
  "hasCompletedOnboarding": true,
```


#### 1.2 配置模型
配置文件位置： ~/.claude/settings.json

  配置内容：
  - ANTHROPIC_BASE_URL: https://api.kimi.com/coding/
  - ANTHROPIC_API_KEY: 你的 Kimi API key

  现在你可以直接运行 claude 命令启动，不需要再手动设置环境变量了。

  额外说明：
  - 此配置保存在全局用户目录，对所有项目生效
  - 如果你想只对当前项目生效，可以使用 .claude/settings.local.json（会被 gitignore）
  - 如需修改，直接编辑 ~/.claude/settings.json 即可
```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.kimi.com/coding/",
    "ANTHROPIC_API_KEY": "sk-kimi-xxxxx",
    "ENABLE_TOOL_SEARCH": "false" 
  }
}
```

ENABLE_TOOL_SEARCH作用：
  - 当设置为 false 时，Claude Code 不会尝试使用 Anthropic 的 tool_search 原生工具
  - 这在使用第三方 API 代理（如 Kimi、OpenRouter 等）时是必要的，因为这些代理通常不支持 Anthropic 特有的 tool_search 功能
